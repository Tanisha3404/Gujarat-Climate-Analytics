# Gujarat Climate Analytics

An end-to-end climate analytics and machine learning project focused on Gujarat, India.

## Features

- Climate data analysis for five Gujarat cities.
- Temperature trend analysis.
- LSTM and CNN-LSTM forecasting.
- Random Forest, XGBoost and LightGBM model comparisons.
- Rainfall prediction analysis.
- Isolation Forest anomaly detection.
- Statistical hypothesis testing.
- Interactive Streamlit dashboard.

## Technologies Used

- Python 3.11
- Pandas and NumPy
- Scikit-learn
- TensorFlow and Keras
- XGBoost and LightGBM
- Matplotlib, Seaborn and Plotly
- Streamlit
- SciPy and Statsmodels

## Run Locally

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Start the dashboard:

```bash
streamlit run dashboard.py
```

## Note

Large datasets and model artifacts are excluded from this GitHub repository and require separate storage configuration for deployment.
